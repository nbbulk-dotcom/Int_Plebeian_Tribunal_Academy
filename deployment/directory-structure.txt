PERMISSION SETTINGS
===================

Folders (755):
- All directories should have permission 755
- This allows: Owner (read/write/execute), Group (read/execute), Public (read/execute)

Files (644):
- All files should have permission 644
- This allows: Owner (read/write), Group (read), Public (read)

Special Files:
- .htaccess should be 644 (readable by server)
- index.html should be 644 (readable by public)

TROUBLESHOOTING FILE PATHS
===========================

If styles don't load:
- Check /css/ folder exists
- Verify main.css is inside /css/
- Check file permissions (644)

If images don't load:
- Check /images/ folder exists
- Verify academy-logo.svg is inside /images/
- Check file permissions (644)

If JavaScript doesn't work:
- Check /js/ folder exists
- Verify app.js and verification.js are inside /js/
- Check file permissions (644)
- Check browser console for errors (F12 → Console tab)

If historical site doesn't load:
- Check /historical/ folder exists
- Verify ZARindex.html is inside /historical/
- Check folder permissions (755)
- Check all historical HTML files have 644 permissions


MAINTENANCE
===========

To update the site:
1. Always backup current files first
2. Replace individual files or entire directories
3. Clear browser cache after updates
4. Test thoroughly before announcing changes

To add new content:
1. Add new HTML files to root or appropriate subfolder
2. Update navigation in index.html if needed
3. Maintain consistent style using existing CSS classes
4. Update service-worker.js if caching new critical files
