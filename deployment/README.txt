================================================================================

1. EXTRACT FILES
   - Extract this ZIP file to your computer's Desktop
   - You should see: index.html, css/, js/, images/, historical/, etc.

2. DEPLOY TO AFRIHOST
   - Follow the step-by-step guide in: afrihost-upload-guide.md
   - This guide is foolproof - just follow each numbered step
   - Estimated time: 40 minutes

3. TEST LOCALLY FIRST (Optional but Recommended)
   
   WINDOWS:
   - Double-click: test-site.bat
   - Site opens at http://localhost:8000
   
   MAC/LINUX:
   - Open Terminal
   - Navigate to this folder
   - Run: chmod +x test-site.sh
   - Run: ./test-site.sh
   - Site opens at http://localhost:8000

4. VERIFY DEPLOYMENT
   - Use deployment-checklist.md to verify everything works
   - Check off each item as you test
