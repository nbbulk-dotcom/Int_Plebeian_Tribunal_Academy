# Tribal Coin and File Verification System

This directory contains the Ethereum-compatible smart contracts for the Tribal Coin (TC) economic system and blockchain file verification.

## Overview

The blockchain layer implements democratic governance, transparent financial operations, and immutable file verification through smart contracts.

## Smart Contracts

### TribalCoin.sol
- **Total Supply**: 1 billion TC tokens
- **Governance**: Democratic voting and proposal management
- **Economics**: Merit-based rewards and chapter funding
- **Security**: Multi-signature wallets and time-locked governance

### FileVerification.sol
- **File Registry**: Immutable file verification system
- **Version Control**: File versioning and update tracking
- **Authorization**: Authorized uploader management
- **Audit Trail**: Complete file history and metadata

## Token Distribution

- **Chapter Operations (40% - 400M TC)** - Monthly operational funding
- **Member Rewards (25% - 250M TC)** - Content creation and participation incentives
- **Mutual Aid Fund (20% - 200M TC)** - Emergency assistance and disaster relief
- **Development & Infrastructure (10% - 100M TC)** - Platform development and maintenance
- **Reserve Fund (5% - 50M TC)** - Long-term sustainability and market stability

## Features

- **Democratic Governance** - Blockchain-based voting mechanisms
- **Transparent Finance** - All transactions publicly auditable
- **Smart Contracts** - Automated execution of organizational decisions
- **Multi-signature Security** - Enhanced security for critical operations
